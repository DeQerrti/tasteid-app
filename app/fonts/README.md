# Шрифты в составе приложения

Здесь лежат гарнитуры, которые страницы раньше тянули с Google Fonts.
Для сайта это было нормально, для приложения — нет: оно работает с
папкой на диске и без интернета, а без сети гарнитуры не приезжали и
вид «уезжал» на системные. Плюс каждая страница локального приложения
ходила за ними на чужой сервер.

Правила `@font-face` — в `app/fonts.css`, сами файлы — рядом.

## Что именно взято

Из пакетов [Fontsource](https://fontsource.org) версии **5.3.0**:
`@fontsource/playfair-display`, `@fontsource/cormorant-garamond`,
`@fontsource/dm-sans`, `@fontsource/caveat`, `@fontsource/patrick-hand`.
Это те же гарнитуры и с той же лицензией (SIL OFL), что отдавал Google.

Взяты ровно те начертания, что перечислял прежний `<link>`:

| Гарнитура          | Начертания                          |
| ------------------ | ----------------------------------- |
| Playfair Display   | 400, 700, 900 + курсив 400, 700     |
| Cormorant Garamond | 300, 400, 600 + курсив 300, 400     |
| DM Sans            | 300, 400, 500                       |
| Caveat             | 600, 700                            |
| Patrick Hand       | 400                                 |

Наборы символов — только `latin`, `latin-ext`, `cyrillic`,
`cyrillic-ext`; греческий и вьетнамский выброшены. Формат только
`woff2` (Chromium его понимает, а `.woff` рядом удвоил бы вес). Итого
около 1 МБ вместо 11 МБ полных пакетов.

**У DM Sans кириллицы нет** — её нет и в самом шрифте, так что русский
текст в нём подхватывает системный, как и раньше на сайте. Это не
недосмотр сборки, а свойство гарнитуры.

## Как пересобрать

`unicode-range` в каждом правиле должен совпадать с тем, что отдаёт
Fontsource, — поэтому правила не пишутся руками, а берутся из его же
CSS. Порядок такой:

```
npm pack @fontsource/playfair-display@5.3.0   # и остальные четыре
tar -xzf fontsource-<имя>-5.3.0.tgz
```

Дальше из `package/<вес>.css` берутся блоки `@font-face` нужных наборов,
в `src:` остаётся только `woff2` с путём `/fonts/<файл>`, а сами файлы
копируются из `package/files/`.
