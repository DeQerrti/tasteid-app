# Проверки, Windows и браузерные тесты

> Часть инструкции для ассистента; короткая главная — `CLAUDE.md` в корне репозитория.
> Читай целиком перед тем, как говорить «готово», и при странных падениях проверок/CI.

## Проверки перед пушем

`npm run check` — обязательный минимум (линт, форматирование, i18n,
дубли функций, структурные проверки, юнит-тесты). `npm run test:browser`
— отдельный набор проверок в настоящем Chromium через Playwright
(жесты пальцем, синхронизация, мобильный мост) — не входит в `check`,
гоняется отдельно и в CI отдельным джобом, но перед серьёзными
изменениями в `app/js/` стоит прогнать и его.

Особенности локального запуска на Windows (рабочая копия owner'а —
`C:\Users\entzi\OneDrive\Documents\GitHub\tasteid-app`):

- `npm run format:check` ругается примерно на 30 нетронутых файлов —
  это переводы строк CRLF (`core.autocrlf=true`), а не ошибка.
  Проверяй свои файлы `npx prettier --check --end-of-line auto <файлы>`.
- `npm run test:browser` на Windows проходит целиком. Раньше файлы с
  мобильным мостом (`backup.mjs`, `sync.mjs`, `mobile-bridge.mjs`,
  `mobile-cover-compress.mjs`) падали с `spawnSync npx ENOENT`: сборка
  тестового бандла звала `npx`, а на Windows это `npx.cmd`. Теперь
  `tests/fixtures/mobile-bundle.js` собирает бандл через сам модуль
  esbuild (`buildSync`) — не возвращай туда ни `npx`, ни запуск
  `node_modules/esbuild/bin/esbuild` через `node`: второй работает на
  Windows, но на Linux этот файл — настоящая программа, а не скрипт, и
  CI на нём падает (так уже было один раз).
- В CI `backup.mjs` изредка падает случайно («Скачать резервную копию»
  не дошло до «Поделиться»), хотя тот же коммит в соседнем прогоне
  проходит. Сначала перезапусти упавший джоб (`gh run rerun <id>
--failed`), и только если падает снова — ищи причину.

**Грабли этой сессии:**

- Регулярки в коде, вставляемом через heredoc/`node -e` из Bash, теряют
  обратные слэши (`/^https?:\/\//` превратилась в `/^https?:///` — то
  есть в `/^https?:/` и комментарий до конца строки, а ESLint такое
  пропускает). Код с регулярками правь через Edit.
- Зашитые порты в браузерных тестах ловят чужие программы (8971 занял
  игровой клиент owner'а). `chars-favorites-cover-cleanup.mjs` теперь
  берёт свободный порт у системы; ещё четыре теста с зашитыми портами
  (`cover-backup-cleanup`, `cover-export`, `mobile-update-settings`,
  `tierlist-export-scale`) — так же, если начнут падать.

- `sed -i` в Git Bash превращает CRLF в LF — `check:shared-head` и
  diff ломаются. Правь через Edit или node с `\r\n`.
- `app/` в `.prettierignore` — prettier по ним ничего не делает,
  форматируй руками.
- Встроенный браузер Claude не проигрывает анимации: скриншоты
  выглядят «бледными» (элементы застряли в начале fade-in), а
  html2canvas зависает. Это не баг приложения — проверяй через
  Playwright.
- В Playwright-тестах читай `reviews.json` через `page.evaluate(fetch)`
  (node-`fetch` мимо страницы получал `[]`), а сохранение жди через
  `page.waitForResponse` на `/api/save-…`, а не `waitForFunction`.
- CI иногда падает на установке пакетов Ubuntu (DNS GitHub) — это не
  код, `gh run rerun <id> --failed`.
