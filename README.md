# TasteID

**Личный каталог медиа: аниме, фильмы, сериалы, игры, книги, гачи - в одном приложении.**

TasteID - офлайн-приложение для учёта просмотренного, прочитанного и пройденного: оценки, статусы, теги, статистика и тир-листы. Данные хранятся локально, в обычной папке на устройстве. Синхронизация между устройствами - через приватный репозиторий на GitHub.

Платформы: Windows · macOS · Linux · Android

## Возможности

- **Любые типы медиа** - аниме, фильмы, сериалы, игры, книги, гачи и собственные категории.
- **Настраиваемая шкала оценок** - числа, звёзды или именованные уровни с собственными диапазонами и цветами.
- **Свои статусы** - набор вкладок («Смотрю», «Брошено», «В планах» и т. д.) задаётся пользователем.
- **Тир-листы, теги, статистика** и раздел избранного (персонажи, персоны, свои разделы).
- **Импорт** списков из Shikimori, AniList и других сервисов.
- **Локальное хранение** - без регистрации и стороннего сервера.
- **Синхронизация через GitHub** - бесплатно и без собственного сервера.
- **Несколько хранилищ** на одном устройстве.
- **История версий** файлов и резервные копии.
- Интерфейс на **русском и английском** языках.

## Установка

Скачайте установщик для своей системы со страницы [последнего релиза](https://github.com/DeQerrti/tasteid-app/releases/latest).

| Система                           | Файл                               |
| --------------------------------- | ---------------------------------- |
| Windows                           | `TasteID-Setup-<версия>.exe`       |
| macOS (Apple Silicon, M1 и новее) | `TasteID-<версия>-arm64.dmg`       |
| macOS (Intel)                     | `TasteID-<версия>-x64.dmg`         |
| Linux                             | `TasteID-<версия>-x86_64.AppImage` |
| Android                           | `TasteID-<версия>.apk`             |

Файлы `.yml` и `.blockmap` используются механизмом автообновления, скачивать их не нужно.

### Предупреждения при установке

Приложение не подписано платным сертификатом, поэтому системы показывают предупреждение. Это ожидаемое поведение для проекта без коммерческой подписи.

- **Windows:** в окне «Windows защитила ваш компьютер» нажмите «Подробнее» → «Выполнить в любом случае».
- **macOS:** попытаться открыть приложение, затем зайти в «Системные настройки» → «Конфиденциальность и безопасность» и нажать «Всё равно открыть»
- **Android:** разрешите установку приложений из этого источника. Начиная с версии 0.7.3 APK подписан собственным ключом проекта вместо общего отладочного, поэтому версию 0.7.2 и старше один раз придётся удалить перед установкой новой. Перед удалением сохраните резервную копию или синхронизируйтесь.

## Хранение данных

При первом запуске на компьютере выбирается папка хранилища (по умолчанию `Документы/TasteID`). Все данные - обычные файлы: их можно копировать, помещать в облачную папку или под контроль версий.

На Windows папка «Документы» часто синхронизируется с OneDrive — тогда и хранилище по умолчанию окажется в OneDrive. Это не мешает работе, но если хранилище открыто на двух компьютерах одновременно через OneDrive, а не через синхронизацию TasteID, правки могут конфликтовать. Для нескольких устройств лучше встроенная [синхронизация](#синхронизация).

На Android хранилище создаётся автоматически во внутренних данных приложения. Удаление приложения или «Очистить хранилище» в настройках Android стирает его — перед этим сделайте резервную копию или синхронизируйтесь.

### Несколько хранилищ

На одном устройстве можно вести несколько независимых хранилищ - у каждого свои отзывы, тир-листы и настройки синхронизации. Активно одно хранилище за раз; переключение не удаляет данные.

Настройки → «Приложение» → «Хранилища».

- **Компьютер:** новое хранилище - это новая или уже существующая папка.
- **Android:** задаётся только имя, папку создаёт приложение.

## Синхронизация

Синхронизация использует приватный репозиторий на GitHub в качестве общего хранилища. Собственный сервер не требуется.

Настройки → «Хранилища и синхронизация». Подключение в три шага, все ссылки — прямо в приложении:

1. Создать приватный репозиторий на GitHub (название и «Private» подставляются ссылкой).
2. Создать токен только на этот репозиторий (fine-grained, право Contents: Read and write; срок и право подставляются ссылкой, сам репозиторий отмечается вручную в «Repository access»).
3. Вставить токен и нажать «Подключить».

Если на другом устройстве синхронизация уже подключена, шаг 1 пропускается. Классический токен с правом `repo` тоже работает (тогда приложение создаст репозиторий само), но даёт доступ ко всем репозиториям аккаунта, поэтому предлагается только запасным вариантом.

Если одно и то же изменили на двух устройствах, синхронизация объединяет правки по записям и спрашивает только при настоящем противоречии.

Токен доступа и служебное состояние синхронизации хранятся только на текущем устройстве (`localStorage`) и не попадают ни в резервные копии, ни в экспорт паспорта.

## Перенос данных между устройствами

Помимо синхронизации, данные можно перенести резервной копией:

Настройки → «Приложение» → «Резервная копия».

Копия включает все данные, в том числе загруженные вручную изображения, и сохраняется одним файлом.

> **Резервная копия ≠ паспорт.** «Паспорт» - урезанная версия профиля для того, чтобы делиться им с другими. Он не предназначен для восстановления данных.

На Android сохранение файлов (резервная копия, паспорт, тир-лист картинкой) выполняется через системное меню «Поделиться».

## Удаление

- **Windows:** «Параметры» → «Приложения» → TasteID → «Удалить». Программа ставится для текущего пользователя в `%LOCALAPPDATA%ProgramsTasteID`.
- **macOS:** перетащите TasteID из «Программ» в корзину.
- **Linux:** удалите файл `.AppImage`.

Папка хранилища с отзывами при удалении программы **не трогается** — её можно удалить вручную или подключить к новой установке.

## Конфиденциальность

TasteID не собирает статистику использования, не показывает рекламу и не отправляет данные автору. В сеть приложение обращается только так:

- **GitHub** — проверка обновлений; синхронизация и «Обмен по коду» — только если вы их включили. Секретная ссылка «Обмена» открывается у любого, у кого она есть.
- **AniList, Шикимори, MyAnimeList, TMDB, Steam, Open Library** — только при поиске тайтла или импорте: туда уходят поисковый запрос или ваш ник на этом сервисе.
- **Обложки** загружаются с сайтов, где лежат; если не загрузились напрямую — через открытый сервис картинок wsrv.nl.

Токен синхронизации и ключи TMDB/Steam хранятся только на устройстве. This product uses the TMDB API but is not endorsed or certified by TMDB.

- Нет встроенной базы тайтлов: записи добавляются вручную или импортируются из других сервисов.

```bash

npm run mobile:apk        # сборка .apk (требуется Android SDK)
```

#### Ключ подписи Android

Релизный APK подписывается ключом, который хранится только в секретах репозитория на GitHub (Settings → Secrets and variables → Actions), а не в самих файлах репозитория. Нужны четыре секрета:

| Секрет                      | Что это                           |
| --------------------------- | --------------------------------- |
| `ANDROID_KEYSTORE_BASE64`   | файл ключа, закодированный base64 |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища ключей           |
| `ANDROID_KEY_ALIAS`         | имя ключа (например `tasteid`)    |
| `ANDROID_KEY_PASSWORD`      | пароль ключа                      |

Ключ создаётся один раз командой `keytool` (входит в Java) и дальше не меняется: если его потерять, обновления перестанут ставиться поверх старой версии. Сохраните файл ключа и пароли в надёжном месте, например в менеджере паролей.
