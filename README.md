# TasteID

Личный паспорт интересов: что смотрел, читал и играл, с оценками, тегами,
статистикой и тир-листами. Настольное приложение - данные лежат обычной
папкой на твоём диске.

## Где лежат данные

Папку выбираешь сам при первом запуске (по умолчанию предлагается
`Документы/TasteID`). Это обычные файлы. Их можно скопировать на флешку, положить в облачную
папку, открыть блокнотом или завести под гит - приложение не возражает и
ничего про это не знает.

## Несколько хранилищ

На одном устройстве может быть больше одной такой папки - со своими
отзывами, тир-листами и настройками синхронизации у каждой.
Переключение в настройках (панель «Приложение» → «Хранилища») ничего
не стирает: данные остаются каждое в своей папке, активно — одно.
На компьютере новое хранилище - это выбор папки (новой или уже
существующей, например скопированной с другого устройства вручную);
на телефоне выбирать нечего, там только имя, а саму папку заводит
приложение.

## Телефон

Что сделано иначе, чем на компьютере:

- **Папка не выбирается** — новое хранилище на телефоне заводится
  само, в данных приложения; выбирать для него папку негде и незачем,
  можно только дать имя (несколько хранилищ работают и здесь).
- **Скачивание файла** (паспорт, резервная копия, тир-лист картинкой,
  версия из истории) внутри приложения не работает вовсе - нажатие
  просто пропадает. Поэтому файл перехватывается и уходит в системное
  «Поделиться».

Данные телефона и компьютера живут отдельно и сами по себе не
сходятся. Переносят их резервной копией (настройки → «Приложение» →
«Резервная копия»): всё целиком, включая вручную загруженные картинки,
одним файлом. Не путать с «Паспортом» на соседней вкладке - тот для
показа себя чужим, урезанный, и никогда не пишется обратно в своё же
хранилище. Про синхронизацию между телефоном и компьютером - ниже.

## Синхронизация

Бесплатный способ синхронизировать несколько устройств без своего
сервера: приватный репозиторий на GitHub как общее хранилище, а сам
GitHub - единственный сервер во всей схеме. Настраивается в настройках,
вкладка «Синхронизация».

Токен и служебное состояние синхронизации хранятся только на этом
устройстве (`localStorage`) и никогда не входят ни в резервную копию,
ни в паспорт.

## Сборка

Собираются Windows (`.exe`), macOS (`.dmg`), Linux (`.AppImage`) и
Android (`.apk`), и складываются в черновик релиза здесь же, в закрытом
`tasteid-app` — для собственной проверки перед выпуском. Когда версия
проверена руками и годна к выпуску, она отдельно переносится (файлы
релиза) в публичный [DeQerrti/TasteID](https://github.com/DeQerrti/TasteID)
— только готовые сборки, без кода, — и уже там публикуется. Автообновление
(`electron/update.js`, `mobile/src/main.js`, `package.json: build.publish`)
смотрит на этот публичный репозиторий, не на `tasteid-app`.

Сборка для Android отладочная. Обычную Android отказывается ставить без
подписи, а ключ подписи в открытом репозитории держать нельзя;
отладочная подписана общим ключом и ставится с телефона как есть -
надо только разрешить установку из этого источника.

**Приложение не подписано.** Windows покажет «Windows защитила ваш
компьютер» — надо нажать «Подробнее» → «Выполнить в любом случае».
Подпись стоит от $200 в год и с 2024 года всё равно не убирает
предупреждение сразу.
Это обычная история для небольшого проекта без платного сертификата,
а не признак того, что с приложением что-то не так.

## Обновления

Windows и Linux проверяют GitHub при запуске и раз в сутки; найдя
версию новее установленной, тихо скачивают её в фоне
(`electron-updater`) и предлагают перезапуститься, когда файл готов.
На macOS так не выходит — Gatekeeper блокирует подмену приложения без
платной подписи (Apple Developer, $99/год) и нотаризации, которых
здесь нет и не планируется, поэтому мак только спрашивает GitHub, есть
ли релиз новее, и предлагает открыть страницу загрузки в браузере —
установка вручную. Ручная проверка на всех системах — там же, где
папка хранилища и версия (панель «Приложение» в настройках).

**Телефонов.** Electron их не умеет — как и у Обсидиана, мобильная версия
это отдельная работа. Сайт при этом ставится на телефон как приложение и
работает офлайн.
