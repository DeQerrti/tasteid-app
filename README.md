# TasteID

Личный паспорт интересов: что смотрел, читал и играл, с оценками, тегами,
статистикой и тир-листами. Настольное приложение — данные лежат обычной
папкой на твоём диске, как хранилище у Обсидиана.

Это приложение выросло из сайта [tasteid.ru](https://tasteid.ru). Сайт
никуда не делся и живёт своей жизнью; здесь то же самое, только без
интернета и без чужого сервера.

## Где лежат данные

Папку выбираешь сам при первом запуске (по умолчанию предлагается
`Документы/TasteID`). Внутри:

```
reviews.json           отзывы
favorites.json         любимое: персонажи, персоны, свои разделы
characters-tier.json   тир-лист персонажей
tier-<id>.json         остальные коллекции тир-листа
site-settings.json     всё, что настраивается на экране настроек
covers/                обложки, загруженные с компьютера
chars/                 картинки персонажей
.history/              прошлые версии файлов
```

Это обычные файлы. Их можно скопировать на флешку, положить в облачную
папку, открыть блокнотом или завести под гит — приложение не возражает и
ничего про это не знает.

**Перенос с сайта** — копирование: файлы там называются так же.

## Как это устроено

Фронтенд переехал с сайта **без единой правки** — те же страницы, тот же
`app/js`. Это не совпадение, а способ переезда: приложение поднимает у
себя внутри маленький сервер на `127.0.0.1` и держит те же адреса, что
были на сайте. Страница как ходила за `/api/save-review` и
`/reviews.json`, так и ходит, не зная, что на другом конце теперь папка
на диске.

```
app/            страницы, стили, скрипты — то же, что на сайте
electron/
  main.js       окно, запуск, мост между страницей и системой
  chrome.js     своя рамка окна вместо системной
  server.js     локальный сервер: страницы + /api/*
  api.js        те же адреса, что были у сайта, поверх файлов
  vault.js      чтение и запись хранилища
  ui/           экран приветствия — к сайту отношения не имеет
tests/          проверки api и хранилища на обычном Node
```

Показывать страницы через `file://` не вышло бы: там не работают ни
абсолютные пути (`/js/theme.js`), ни `fetch` за своими же файлами — то
есть фронтенд пришлось бы переписывать целиком.

Порт выбирается свободный на старте: фиксированный номер однажды окажется
занят, и приложение просто не откроется. Слушаем только `127.0.0.1` —
на `0.0.0.0` хранилище было бы открыто любому в той же сети, без пароля,
потому что пароля здесь и не предполагается.

### Первый запуск

Папка неизвестна или пропала — открывается экран приветствия: создать
новый паспорт или открыть готовую папку, а новичку следом пара вопросов
про тему и шкалу оценок. Смысл в том, чтобы человек вошёл в уже
настроенное под себя приложение, а не в чужие умолчания.

Окно приветствия компактное, без возможности развернуть на весь экран
(`maximizable: false` — как у Обсидиана в его мастере создания
хранилища: одна карточка внутри, разворачивать её незачем) и после
настройки вырастает до рабочего размера. `maximizable` официально не
поддерживается на Linux — на Windows и macOS, для которых это и делалось,
работает.

Выбор шкалы оценок на экране приветствия — не три готовых пресета, а тот
же редактор полок, что в `/settings-edit`: имя, цвет, диапазон для
каждой полки, добавить/убрать свою. Логика пересева при переключении
типа тоже позаимствована оттуда один в один: полки заново собираются
только на границе «Названия ↔ диапазон», а между «Числа» и «Звёздами»
правки не теряются — тот, кто уже подправил диапазоны под числа, не
должен потерять их, поставив вместо чисел звёзды.

### Рамка окна

Системный заголовок с меню выглядел чужой полосой поверх тёмной
страницы. `titleBarStyle: "hidden"` его убирает, `titleBarOverlay`
возвращает кнопки окна уже в цветах темы, а полоса для перетаскивания
вставляется стилем из `chrome.js`: у безрамочного окна нет места, за
которое его двигают.

Стиль вставляется из `electron/`, а не лежит в `app/`, — страницы там
копия сайта, и чем меньше они знают о приложении, тем проще держать их
в согласии с ним. Меню тоже не показывается, но заводится: без него
перестают работать Ctrl+= и F5.

### Админ без входа

Признак «я админ» фронтенд читает из куки `tasteid_ui` — на сайте её
ставил вход по паролю. В приложении входить некому и не от кого: папку
открыл тот, кому она принадлежит. Куку ставит сам локальный сервер, на
каждый ответ.

### Настройки самого приложения

Панель «Приложение» в настройках — папка хранилища, масштаб, версия.
Показывается, только когда отвечает `/api/app/info`, то есть когда
страницу открыло приложение, а не браузер. На сайте её нет и быть не
может: там нет ни папки на диске, ни окна.

## Что бережёт данные

**Запись через временный файл.** Прямая запись поверх существующего
оставляет окно, в котором файл уже обрезан, а новое содержимое ещё не
дописано; выключение света в этот момент даёт пустой `reviews.json` и
никакого способа это заметить. Пишем рядом и переименовываем —
переименование атомарно, файл либо старый целиком, либо новый целиком.

**История версий.** На сайте её давал гит: каждое сохранение было
коммитом. Здесь перед каждой перезаписью прошлая версия уезжает в
`.history` (последние 50 на файл). Это то, чем откатывается неудачный
импорт, и то, на что ссылается предупреждение при удалении отзыва.

**Очередь изменяющих запросов.** Каждый из них читает файл, правит и
пишет обратно. Два таких запроса внахлёст читают одно состояние, и правка
того, кто записал первым, теряется — молча, потому что оба ответят
«сохранено». Поэтому они выполняются строго по одному; стоит это ничего,
пользователь всё равно один.

## Разработка

```
npm ci
npm run serve ./vault     страницы в браузере, без Electron
npm start                 приложение целиком
npm run check             линтер, форматирование, тесты
```

`npm run serve` поднимает тот же сервер без графики — так же работают и
тесты, поэтому проверять хранилище можно в обычном Node, без установленного
Electron и без окна.

## Сборка

Установщики собираются на GitHub по тегу:

```
git tag v0.1.0 && git push --tags
```

Собираются Windows (`.exe`), macOS (`.dmg`) и Linux (`.AppImage`), и
складываются в черновик релиза.

**Приложение не подписано.** Windows покажет «Windows защитила ваш
компьютер» — надо нажать «Подробнее» → «Выполнить в любом случае».
Подпись стоит от $200 в год и с 2024 года всё равно не убирает
предупреждение сразу, так что для раздачи друзьям проще предупредить.

## Чего здесь нет по сравнению с сайтом

**Входа по паролю.** Некому логиниться: приложение уже открыто тем, кто
его запустил, и пароль защищал бы папку от её же владельца.

**Потолка в мегабайт.** Он был ограничением GitHub, а не нашим.

**Своих шрифтов.** Страницы тянут гарнитуры с Google Fonts, как тянул
сайт. Без интернета они заменяются системными — приложение работает, но
выглядит иначе. Шрифты надо положить в состав приложения; пока не
сделано.

**Телефонов.** Electron их не умеет — как и у Обсидиана, мобильная версия
это отдельная работа. Сайт при этом ставится на телефон как приложение и
работает офлайн.
