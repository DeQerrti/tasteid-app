# TasteID

**Личный каталог медиа: аниме, фильмы, сериалы, игры, книги, гачи - в одном приложении.**

TasteID - офлайн-приложение для учёта просмотренного, прочитанного и пройденного: оценки, статусы, теги, статистика и тир-листы. Данные хранятся локально, в обычной папке на устройстве. Синхронизация между устройствами - через приватный репозиторий на GitHub.

Платформы: Windows · macOS · Linux · Android

## Возможности

- **Любые типы медиа** - аниме, фильмы, сериалы, игры, книги, гачи и собственные категории.
- **Настраиваемая шкала оценок** - числа, звёзды или именованные уровни с собственными диапазонами и цветами.
- **Свои статусы** - набор вкладок («Смотрю», «Брошено», «В планах» и т. д.) задаётся пользователем.
- **Тир-листы, теги, статистика** и раздел избранного (персонажи, персоны, свои разделы).
- **Импорт** списков из Shikimori, AniList и других сервисов.
- **Локальное хранение** - без регистрации и стороннего сервера.
- **Синхронизация через GitHub** - бесплатно и без собственного сервера.
- **Несколько хранилищ** на одном устройстве.
- **История версий** файлов и резервные копии.
- Интерфейс на **русском и английском** языках.

## Установка

Скачайте установщик для своей системы со страницы [последнего релиза](https://github.com/DeQerrti/tasteid-app/releases/latest).

| Система | Файл |
| --- | --- |
| Windows | `TasteID-Setup-<версия>.exe` |
| macOS (Apple Silicon, M1 и новее) | `TasteID-<версия>-arm64.dmg` |
| macOS (Intel) | `TasteID-<версия>-x64.dmg` |
| Linux | `TasteID-<версия>-x86_64.AppImage` |
| Android | `TasteID-<версия>.apk` |

Файлы `.yml` и `.blockmap` используются механизмом автообновления, скачивать их не нужно.

### Предупреждения при установке

Приложение не подписано платным сертификатом, поэтому системы показывают предупреждение. Это ожидаемое поведение для проекта без коммерческой подписи.

- **Windows:** в окне «Windows защитила ваш компьютер» нажмите «Подробнее» → «Выполнить в любом случае».
- **macOS:** при первом запуске откройте приложение через контекстное меню (правый клик → «Открыть»).
- **Android:** разрешите установку приложений из этого источника. Сборка для Android отладочная и подписана общим отладочным ключом.

## Хранение данных

При первом запуске на компьютере выбирается папка хранилища (по умолчанию `Документы/TasteID`). Все данные - обычные файлы: их можно копировать, помещать в облачную папку или под контроль версий.

На Android хранилище создаётся автоматически во внутренних данных приложения.

### Несколько хранилищ

На одном устройстве можно вести несколько независимых хранилищ - у каждого свои отзывы, тир-листы и настройки синхронизации. Активно одно хранилище за раз; переключение не удаляет данные.

Настройки → «Приложение» → «Хранилища».

- **Компьютер:** новое хранилище - это новая или уже существующая папка.
- **Android:** задаётся только имя, папку создаёт приложение.

## Синхронизация

Синхронизация использует приватный репозиторий на GitHub в качестве общего хранилища. Собственный сервер не требуется.

Настройки → вкладка «Синхронизация».

Токен доступа и служебное состояние синхронизации хранятся только на текущем устройстве (`localStorage`) и не попадают ни в резервные копии, ни в экспорт паспорта.

---

## Перенос данных между устройствами

Помимо синхронизации, данные можно перенести резервной копией:

Настройки → «Приложение» → «Резервная копия».

Копия включает все данные, в том числе загруженные вручную изображения, и сохраняется одним файлом.

> **Резервная копия ≠ паспорт.** «Паспорт» - урезанная версия профиля для того, чтобы делиться им с другими. Он не предназначен для восстановления данных.

На Android сохранение файлов (резервная копия, паспорт, тир-лист картинкой) выполняется через системное меню «Поделиться».

## Обновления

| Платформа | Поведение |
| --- | --- |
| Windows, Linux | Проверка при запуске и раз в сутки. Новая версия скачивается в фоне, после чего приложение предлагает перезапуститься. |
| macOS | Приложение сообщает о новой версии и открывает страницу загрузки; установка вручную. Автоматическая замена невозможна без подписи и нотаризации Apple. |
| Android | Установка новой версии вручную из релиза. |

Проверить обновления вручную можно в настройках → «Приложение».

## Известные ограничения

- Нет встроенной базы тайтлов: записи добавляются вручную или импортируются из других сервисов.
- Приложение не подписано (см. [Предупреждения при установке](#предупреждения-при-установке)).
- На macOS обновления устанавливаются вручную.

## Разработка

```bash
npm ci
npm start                 # запуск приложения
npm run serve ./vault     # интерфейс в браузере, без Electron
npm run check             # линтер, форматирование, тесты
```

### Android

```bash
npm run build:mobile      # сборка мобильного моста
npm run mobile:sync       # то же + копирование страниц в проект Android
npm run mobile:apk        # сборка .apk (требуется Android SDK)
```

### Сборка релиза

Установщики для всех платформ собираются GitHub Actions по тегу и публикуются в черновик релиза:

```bash
git tag v0.1.0 && git push --tags
```
